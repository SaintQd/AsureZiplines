## AsureZiplines

Плагин, добавляющий возможность создавать канатные дороги (зиплайны) и перемещаться по ним. Работают по принципу размещаемых
в мире сущностей BLOCK_DISPLAY, представляющих собой зиплайн, на линии размещения которых процедурно рассчитываются точки
перемещения игрока. В результате образуется система, позволяющая с заданной в конфигурационном файле мерой точности перемещаться
по зиплайну в обе стороны.

---

## Модули и возможности

- **Зиплайны**: Объект, соединяющий собой две точки линией из сущностей `BLOCK_DISPLAY`, имитирующих вид канатной дороги.
Могут быть размещены с помощью специальных предметов создания зиплайна и командой. Игроки могут перемещаться по зиплайну, нажав предметом,
указанным в конфигурационном файле, на одну из двух конечных точек, которые были указаны при создании зиплайна.
- **Создание и удаление зиплайна**: Для создания и удаления зиплайна используются специальные предметы. Предмет создания позволяет
отметить две точки, между которыми будет протянут зиплайн, а затем ввести команду для финализации процесса создания. 
Предмет удаления позволяет удалить созданный зиплайн, нажав ПКМ по одной из двух точек, которые были указаны при создании зиплайна.\
Любой предмет может быть предметом создания или удаления зиплайна при наличии необходимого свойства PersistentDataContainer.
- **Требования зиплайна**: В конфигурационном файле можно указать требования, которые должны выполняться при создании зиплайна.
Зиплайн может быть ограничен по общей длине. Также для создания зиплайна может потребоваться заданное количество предметов.
В креативе на игрока не действуют требования по количеству предметов.

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Для одной из зависимостей требуется наличие локального артефакта плагина AsureLib. Путь до артефакта должен
выглядеть следующим образом относительно папки проекта: `../AsureLib/build/libs/AsureLib-1.0-SNAPSHOT.jar`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию плагина можно отключить или перенастроить.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
